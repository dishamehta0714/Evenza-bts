# 🍽️ Evenza - Catering & Event Planning Website



Evenza is a modern, responsive **catering and event planning website** built using **Bootstrap 5**. It showcases services like weddings, corporate events, parties, and more with smooth animations and a clean UI.

---

## 🚀 Features

* ✅ Fully responsive design (mobile-friendly)
* 🎞️ Hero carousel with event categories
* 📖 About Us section
* 🛠️ Services showcase with image grid
* 🍴 Menu section with card overlays
* 👨‍🍳 Team members display
* 🖼️ Gallery section
* 📍 Google Maps integration
* 📬 Contact form
* ✨ Smooth animations using AOS (Animate On Scroll)

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* AOS Animation Library
* Font Awesome Icons
* Hover.css

## ⚙️ Installation & Usage

1. Clone or download this project
2. Open the folder
3. Run `index.html` in your browser

No additional setup required 🚀

---

## 🎨 Customization

You can easily customize colors using CSS variables:

```css
:root {
  --bg-color: #e9c0a4;
  --bg-color2: #e1a984;
}
```

Modify images inside the `/asset` folder to personalize your website.
